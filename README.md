# NicheMRF

Using Markov Random Fields to identify functional niches in spatial transcriptomic data.

**This project is in active development.**

## Overview

This project applies Markov Random Fields (MRFs) to spatial transcriptomics data to identify functional niches, distinct groups of neighboring cells with predictable intercellular interactions and gene expression patterns.

## Installation

```bash
# Clone the repository
git clone https://github.com/thosib/NicheMRF.git
cd NicheMRF

# Build and run Docker container
docker-compose up -d

# Or install locally
pip install -r docker/requirements.txt
```
